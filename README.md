# SillyTavern Bulk Tagger
An extention for SillyTavern that allows for bulk tagging characters all at once!

## How to install
Go to the extentions tab and click `Install Extention`.

Add the repo `https://github.com/NotNotEnder/ST-Bulk-Tagger.git`.
